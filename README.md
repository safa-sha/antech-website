# ANTECH — Security & Technology Solutions

A modern business website for **ANTECH**, showcasing its security systems, technology services, certifications, and business partners.

## Overview

ANTECH provides security and technology solutions for residential, commercial, and industrial environments. This website presents the company's services, credentials, and contact information through a clean, modern interface.

## Features

- **Interactive 3D Hero Section** — A product-focused landing page featuring a 3D CCTV camera model.
- **Services Showcase** — Dedicated service cards with images and descriptions.
- **Certifications & Credentials** — A section highlighting company credentials.
- **Partner Showcase** — Displays partner brands and logos.
- **Contact Section** — Provides visitors with company contact information.
- **Responsive Design** — Designed to work across desktop and mobile screen sizes.
- **Smooth Animations** — Subtle transitions and interactive visual effects.

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Three.js
- React Three Fiber

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd antech-website
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
